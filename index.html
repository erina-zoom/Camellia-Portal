🍎 iPhoneでの使い方

Camellia Portalをホーム画面に追加すると、 次回からホーム画面のアイコンをタップするだけで、 すぐに開くことができます。

パターン①

Safariの画面右下に「・・・」が 表示されている場合

SafariでCamellia Portalを開いた状態から、 以下の手順でホーム画面に追加してください。

  1. 画面右下の「・・・」を押します。
  2. 「共有」を押します。
  3. 右下の「表示を増やす」を押します。
  4. 「ホーム画面に追加」を押します。
  5. 右上の「追加」を押します。

パターン②

Safariの画面下に「共有」ボタン （□↑）が表示されている場合

SafariでCamellia Portalを開いた状態から、 以下の手順でホーム画面に追加してください。

  1. 画面下の「共有」ボタンを押します。
  2. 右下の「表示を増やす」を押します。
  3. 「ホーム画面に追加」を押します。
  4. 右上の「追加」を押します。

🟦 iPadでの使い方

iPadでのホーム画面への追加方法を こちらで確認できます。

ホーム画面に追加

  1. SafariでCamellia Portalを開きます。
  2. 共有メニューを開きます。
  3. 「ホーム画面に追加」を選びます。
  4. 「追加」を押します。

🤖 Androidでの使い方

AndroidではChromeからホーム画面に 追加できます。

ホーム画面に追加

  1. ChromeでCamellia Portalを開きます。
  2. 右上の「︙」を押します。
  3. 「ホーム画面に追加」または 「ショートカットを作成」を選びます。
  4. 表示された画面で、名前を確認・変更します。
  5. 「追加」を押します。
