🍎 iPhoneでの使い方

Camellia Portalをホーム画面に追加すると、 次回からすぐに開くことができます。

パターン①

Safariに「共有」ボタン （□↑）が表示されている場合

  1. SafariでCamellia Portalを開きます。
  2. 「共有」ボタンを押します。
  3. 「ホーム画面に追加」を選びます。
  4. 「追加」を押します。
ここに共有ボタンの画像を表示

パターン②

「…」から共有する場合

  1. SafariでCamellia Portalを開きます。
  2. 「…」を押します。
  3. 「共有」を押します。
  4. 「表示を増やす」などから 「ホーム画面に追加」を選びます。
  5. 「追加」を押します。
ここに操作画面の画像を表示

🟦 iPadでの使い方

iPadでのホーム画面への追加方法を こちらで確認できます。

ホーム画面に追加

  1. SafariでCamellia Portalを開きます。
  2. 共有メニューを開きます。
  3. 「ホーム画面に追加」を選びます。
  4. 「追加」を押します。
ここにiPadの操作画像を表示

🤖 Androidでの使い方

AndroidではChromeからホーム画面に 追加できます。

ホーム画面に追加

  1. ChromeでCamellia Portalを開きます。
  2. 右上の「︙」を押します。
  3. 「ホーム画面に追加」または 「アプリをインストール」を選びます。
  4. 「追加」または「インストール」を押します。
